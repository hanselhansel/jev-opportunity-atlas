# L11: Need-card engine (Jev assigns, merges, verifies)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Branch: feat/l11-need-cards

**Goal:** Jev places every firsthand problem comment on a need card through a two-level choice (group, then card, each with "none of these"). It then merges duplicate cards with a 3-level score, verifies each membership with a yes/no question, and checks planted synthetic problems. Claude (the main session, not this lane) writes card text; this lane only builds the machinery.

**Architecture:** New package `src/atlas/cards/engine/` plus a small, backward-compatible extension to the runner so an item can carry its own `state` and `questions`. Card sets are versioned YAML files under `configs/cards/` (contract `CARDS` columns). All Jev work goes through `atlas.inference.runner.run_batch`, so ledger, budget guard, cache, and resume come for free. Results are written as contract `ASSIGNMENTS`.

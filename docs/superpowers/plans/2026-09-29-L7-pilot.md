# L7: Pilot command and pilot report

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Branch: feat/l7-pilot (starts after L1, L2, and L3 are merged to `main`)

**Goal:** One command that draws the pilot sample, runs the screen and deep question sets through the budgeted runner, and writes a pilot report with measured cost, tokens, latency, and answer distributions, plus projections for the main run.

**Architecture:** Orchestration only. It composes `atlas.sampling.select.draw`, `atlas.inference.runner.run_batch`, and `atlas.inference.ledger.summarize`. Deep questions run on every pilot comment (not only screen positives) so the pilot measures what a screen gate would drop.

**Tech Stack:** Python 3.11, duckdb, pyarrow.

Read first: `AGENTS.md`, `src/atlas/contracts.py`, `src/atlas/sampling/select.py`, `src/atlas/inference/runner.py`, `configs/questions/*.v0.json`, spec sections 4, 5, 8.

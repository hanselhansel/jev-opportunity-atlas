> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Branch: feat/l6-site

**Goal:** A working Observable Framework site with all seven pages, linked filters, lane selector, provenance badges, and a persistent fictional-data banner, built from synthetic fixtures so real data can be dropped in later without layout changes.

**Architecture:** `site/` is an Observable Framework project (pinned `@observablehq/framework@1.13.4`). Python data loaders (`*.parquet.py`) emit Parquet from `ATLAS_SITE_DATA` (a directory of exported site tables) or, when unset, from `site/fixtures/` synthetic tables and set `mode = "fixture"`. Pages query Parquet in the browser with DuckDB-WASM (`DuckDBClient`) and draw with Observable Plot. The site never calls TypeSafe. In public mode the Evidence page fetches comment text from `https://hacker-news.firebaseio.com/v0/item/<id>.json` in the reader's browser (CORS verified 2026-09-28 for `hanselhansel.github.io`).

**Tech Stack:** Node 24, Observable Framework 1.13.4, Observable Plot, DuckDB-WASM, Python loaders (pyarrow, numpy).

### Site table contract (frozen for plan 2)

Every table the site reads, all Parquet, all text-free:

| table | columns |
|---|---|
| `meta` | key, value (includes mode, snapshot_id, run_id, window_start, window_end, built_at) |
| `coverage` | dimension, key, count |
| `domain_share` | lane, domain, month, n, weighted_share, ci_low, ci_high, too_few, badge |
| `evidence` | comment_id, lane, domain, subtopic, month, story_id, thread_type, firsthand_p, account_type, specificity, workaround_p, consequence_any_p, evidence_strength, support_sentence_id, model_returned, run_id, human_label |
| `findings` | finding_id, title, domain, subtopic, n_comments, n_threads, n_authors, months_present, contradicting, status, lane |
| `runs` | run_id, phase, calls, attempts, retries, unknown_attempts, calculated_usd, wall_s, p50_ms, p95_ms, cache_hits, kind |
| `quality` | question_id, label_set, metric, value, ci_low, ci_high, n |

`badge` is one of `measured`, `calculated`, `estimated`, `unknown`.

```python
import os
import sys
from pathlib import Path

import pyarrow.parquet as pq

src = os.environ.get("ATLAS_SITE_DATA")
if src:
    path = Path(src) / "domain_share.parquet"
else:
    from atlas.sitedata.tables import write_fixtures
    fixtures = Path(__file__).resolve().parents[2] / "fixtures"
    write_fixtures(fixtures, seed=0)
    path = fixtures / "domain_share.parquet"
pq.write_table(pq.read_table(path), sys.stdout.buffer)
```

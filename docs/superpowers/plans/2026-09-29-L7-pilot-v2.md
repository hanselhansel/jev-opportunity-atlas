# L7 (v2): Staged pilot for the $25 design

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Branch: feat/l7-pilot-v2

This plan replaces `2026-09-29-L7-pilot.md` (written before the $25 cap and the analysis design). Do not implement the old plan.

**Goal:** A cheap, staged pilot (target under $0.15 of the $0.50 `pilot` cap) that measures what the main run needs:
- firsthand rate and tokens per call in each v2 design stratum (inputs to `sample allocate-v2`);
- facet costs;
- the accuracy of packing several comments into one call;
- behavior on injected-instruction cases.

It also produces the calibration label queue and gold-draw records that PPI needs. The main session (Claude) runs every paid step by hand; this lane builds the commands and tests them with the mock.

**Architecture:** New package `src/atlas/pilot/` with one module per stage. It composes merged code:
- `atlas.sampling.design_v2` and `yield_alloc` (L10)
- `atlas.sampling.select` (L2)
- `atlas.sources.items.load_items` (L1)
- `atlas.inference.runner.run_batch`, including per-item `state`/`questions` (L3, L11)
- `atlas.inference.budget.BudgetGuard.for_budget` (L3; the account cap from L9 when merged)
- `atlas.evaluation.queue` (L4)

Each stage writes to its own run directory so the numbers `sample allocate-v2` reads stay clean:

| Stage | Run ID | Question set |
|---|---|---|
| Screen and facets | `pilot-<seed>` | `screen@1`, then `facets@1` |
| Packed experiment | `pilot-<seed>-packed` | `packed-screen@1` |
| Injected cases | `pilot-<seed>-injected` | `screen@1` and `facets@1` |

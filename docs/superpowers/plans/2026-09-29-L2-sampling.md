# L2: Sampling frame, stratified selection, weights, cluster bootstrap

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Branch: feat/l2-sampling

**Goal:** Reproducible probability samples over eligible comments, with stored inclusion probabilities and weights, recorded expansions, and weighted estimates with thread-clustered bootstrap intervals.

**Architecture:** Pure functions over pyarrow tables. The frame is the eligible rows of `comments.parquet` joined to story engagement. Strata are frozen labels. Selection uses numpy's PCG64 with a stored seed over IDs sorted ascending, so the same seed and frame always give the same sample. Manifests are Parquet (contract `SAMPLE`) plus a JSON sidecar.

**Tech Stack:** Python 3.11, pyarrow, numpy, duckdb.

# tests/sampling/test_select.py
import pyarrow as pa
import pytest

from atlas.sampling.select import allocate, draw, expand


def frame(n_a=600, n_b=300, n_c=100):
    ids = list(range(1, n_a + n_b + n_c + 1))
    strata = ["A"] * n_a + ["B"] * n_b + ["C"] * n_c
    return pa.table({"comment_id": ids, "story_id": [i // 10 for i in ids], "stratum": strata})


def test_proportional_allocation_sums_exactly():
    assert allocate({"A": 600, "B": 300, "C": 100}, 101) == {"A": 61, "B": 30, "C": 10}


def test_min_per_stratum_is_honored_without_exceeding_size():
    alloc = allocate({"A": 600, "B": 300, "C": 2}, 50, min_per_stratum=5)
    assert alloc["C"] == 2 and sum(alloc.values()) == 50


def test_draw_is_reproducible_and_weights_match():
    s1 = draw(frame(), n=100, seed=7, sample_id="s")
    s2 = draw(frame(), n=100, seed=7, sample_id="s")
    assert s1.column("comment_id").to_pylist() == s2.column("comment_id").to_pylist()
    rows = s1.to_pylist()
    a = [r for r in rows if r["stratum"] == "A"]
    assert len(a) == 60
    assert a[0]["inclusion_prob"] == pytest.approx(60 / 600)
    assert a[0]["weight"] == pytest.approx(10.0)
    assert sum(r["weight"] for r in rows) == pytest.approx(1000)
    assert {r["batch"] for r in rows} == {1}


def test_different_seed_differs():
    a = draw(frame(), n=100, seed=7, sample_id="s").column("comment_id").to_pylist()
    b = draw(frame(), n=100, seed=8, sample_id="s").column("comment_id").to_pylist()
    assert a != b


def test_expand_adds_new_units_and_recomputes_probabilities():
    s1 = draw(frame(), n=100, seed=7, sample_id="s")
    s2 = expand(frame(), s1, extra=100, seed=8)
    ids = s2.column("comment_id").to_pylist()
    assert len(ids) == len(set(ids)) == 200
    rows = s2.to_pylist()
    a = [r for r in rows if r["stratum"] == "A"]
    assert len(a) == 120 and all(r["inclusion_prob"] == pytest.approx(120 / 600) for r in a)
    assert {r["batch"] for r in rows} == {1, 2}
    assert sum(r["weight"] for r in rows) == pytest.approx(1000)
```

- [ ] **Step 2: Fail. Step 3: Implement** in `select.py`:
  - `allocate(sizes: dict[str,int], n: int, min_per_stratum: int = 0) -> dict[str,int]`: proportional allocation with Hamilton (largest remainder) rounding, ties broken by stratum label ascending. Apply `min(size, min_per_stratum)` floors first, then allocate the remainder proportionally over remaining capacity. Never exceed a stratum's size. Raise `ValueError` when `n` exceeds the frame.
  - `draw(frame, n, seed, sample_id, min_per_stratum=0) -> pa.Table` matching contract `SAMPLE`: for each stratum in sorted label order, take IDs sorted ascending and pick `n_h` with `numpy.random.Generator(numpy.random.PCG64(seed)).choice(len, n_h, replace=False)`, using one generator advanced across strata in label order. `inclusion_prob = n_h / N_h`, `weight = N_h / n_h`, `batch = 1`, `draw_order` is the running position.
  - `expand(frame, previous, extra, seed, min_per_stratum=0) -> pa.Table`: allocate `extra` proportionally over remaining (unselected) units, draw from the remaining units with the new seed, set `batch = max(previous.batch) + 1` on new rows, and recompute `inclusion_prob` and `weight` for all rows from the new totals per stratum. This treats the combined sample as stratified simple random sampling of the combined size, which holds because each batch is a simple random draw from the units not yet selected.
  - `write_manifest(table, meta: dict, out_dir) -> dict`: writes `<sample_id>.parquet` and `<sample_id>.json` with `seed`, `seeds_by_batch`, `algorithm` (`"stratified SRSWOR, Hamilton proportional allocation, PCG64"`), `cutpoints`, per-stratum `N_h` and `n_h`, `frame_snapshot_id`, file SHA-256.

# tests/sampling/test_estimate.py
import numpy as np
import pytest

from atlas.sampling.estimate import weighted_proportion


def test_point_estimate_uses_weights():
    est = weighted_proportion(
        y=[1, 0, 1, 0], w=[1, 1, 3, 3], strata=["A", "A", "B", "B"], clusters=[1, 2, 3, 4],
        n_boot=200, seed=0)
    assert est["estimate"] == pytest.approx(0.5)
    assert est["n"] == 4 and est["weighted_n"] == pytest.approx(8)


def test_clustered_interval_is_wider_than_naive_when_threads_are_homogeneous():
    rng = np.random.default_rng(0)
    clusters = np.repeat(np.arange(40), 10)
    y = np.repeat(rng.integers(0, 2, 40), 10)  # whole threads agree
    kwargs = dict(y=y, w=np.ones(400), strata=["A"] * 400, n_boot=500, seed=1)
    clustered = weighted_proportion(clusters=clusters, **kwargs)
    naive = weighted_proportion(clusters=np.arange(400), **kwargs)
    width = lambda e: e["ci_high"] - e["ci_low"]
    assert width(clustered) > 2 * width(naive)


def test_small_counts_are_flagged():
    est = weighted_proportion(y=[1] * 5 + [0] * 5, w=[1] * 10, strata=["A"] * 10,
                              clusters=list(range(10)), n_boot=100, seed=0, min_hits=30)
    assert est["too_few"] is True
```

## Amendments from the plan review (2026-09-29). These override anything above.

**A1. Strata use periods, not calendar months.** Stratum label is
`f"{period}|{thread_type}|{tier}"` where `period` is the `COMMENTS.period` column
(`P01`..`P12`). Update the frame test's input column from `month` to `period`
(values `P01`, `P02`) and its expected labels accordingly. A story with null
`descendants` gets tier `e0`.

**A2. No zero-probability strata.** `draw` takes `min_per_stratum=2` by default. When
`n` cannot give every nonempty stratum 2 units, collapse strata first: drop the
engagement tier (`period|thread_type`), then drop thread type (`period`), and record the
collapse level in the manifest. After drawing, assert `sum(weight) == N_frame` (within
1e-6) and that every nonempty stratum has `n_h >= 1`; raise `SamplingError` otherwise.

**A3. `expand` rule.** Add to its docstring: the extra size and its allocation may depend
only on stratum counts, never on observed answers. Otherwise the recomputed
probabilities are wrong.

**A4. Bootstrap corrections in `weighted_proportion`.**
- Rao-Wu rescaling: in stratum h with `m_h` clusters, draw `m_h - 1` clusters with
  replacement and multiply each drawn row's weight by `m_h / (m_h - 1)` times its draw
  count.
- A stratum with one cluster contributes no variance; count such strata and return
  `single_cluster_strata`.
- Finite-population correction: accept `fpc` (sampling fraction per stratum, `n_h/N_h`);
  when every stratum has fraction 1 (census), return `ci_low == ci_high == estimate`.
- Domain estimation: accept `domain` (bool array). Each replicate computes
  `sum(w*y*d)/sum(w*d)` on the full sample; never subset rows before resampling.
- Chunk replicates in blocks of 100 to bound memory.
- Docstring: threads are not the sampling unit; the cluster bootstrap is a conservative,
  model-based approximation. Threads crossing periods are treated as separate clusters
  per stratum.
